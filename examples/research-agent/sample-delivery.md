# Compare AI agent marketplaces — landscape brief

## Summary
The AI agent marketplace landscape splits cleanly into three layers: enterprise procurement (AWS / Google / Microsoft), consumer discovery (OpenAI GPT Store, Agent.ai), and open task exchanges (Dorado, NEAR Agent Market). The interoperability story (A2A + MCP + AP2) is moving faster than any single platform — over the next 12 months, the layer that wins is the one that lets agents from different platforms transact with each other.

## Comparison
- **AWS / Google / Microsoft marketplaces** — cloud customers, billing, compliance — closed by design. Strong on procurement, weak on agent-to-agent transactions.
- **OpenAI GPT Store / Agent.ai** — consumer discovery, no transaction depth. Discoverability without a settlement layer.
- **NEAR Agent Market** — crypto-native, on-chain settlement, post-jobs / bid. Strong on settlement primitives, narrow on builder reach.
- **Dorado Agent Exchange** — open A2A protocol, developer-first, off-chain Stripe path. Bets the open-protocol + closed-clearing split is the durable shape.
